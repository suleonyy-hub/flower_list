# 🪷 參拜宮廟蓮花樣式顏色統計工具（v17.0）

專為參拜宮廟備料與現場登記設計的輕量化統計工具，支援**手機離線單人登記**、**多人雲端雙向同步**、**品項已完成進度勾選**、**歷史紀錄快速複製**，以及**直式 A4 PDF 備料明細單匯出**（完整相容 WebIntoApp 打包之 Android APK）。

## ✨ 核心功能一覽

1. **8 大蓮花品項與 13 色快速勾選**
   * 支援品項：**菩提百合花盤**（花/葉可累計 1～4）、**小花**、**大小花**、**水蓮花**、**大小水蓮花**、**雙瓣蓮花**，以及 **能量寶璃花（富貴蓮 4 片／掌心蓮 8 片編號槽位，允許重色）**。
   * 支援「同花色／同外層」一鍵連動與「一次新增多組獨立卡片（#1、#2…）」。

2. **個人品項「已完成」勾選備註（v17.0 新增）**
   * **填表時標記**：在「✏️ 個人登記」展開任一品項卡片，可勾選 **「勾選標記為『已完成』」**，卡片標題列會即時亮起綠色 **`✓ 已完成`** 標籤。
   * **檢視時快速勾選**：在「📋 查詢與紀錄」檢視個人紀錄卡片時，每個品項標籤左側皆附有獨立勾選框，無需進入編輯即可一鍵勾選或取消完成狀態，並自動儲存同步。
   * **明細與 PDF 連動**：已勾選項目會在品項明細自動加註 `（✓已完成）`，匯出直式 A4 PDF 備料單時，右側核對欄也會自動顯示為已勾選的 **`☑`**。

3. **歷史紀錄查詢與整批複製**
   * 依「參拜宮廟」、「參拜日期」或「姓名關鍵字」快速篩選。
   * 支援單筆套用或「整批複製到新宮廟／日期」，省去重複勾選時間。

4. **彙整總計與各色頻次自動換算**
   * 自動統計各品項總件數、人員明細，以及 13 種顏色的總使用次數（自動將「同花色」計入對應顏色）。

5. **直式 A4 PDF 匯出（雙模式相容）**
   * **電腦／手機瀏覽器**：純前端離線即時渲染標準直式 A4 PDF 並下載。
   * **Android APK（WebIntoApp）**：自動偵測 APK 環境，透過 Google Apps Script 後端生成實體 A4 PDF 並觸發系統原生下載器，徹底解決 WebView 無法檢視 `blob:` PDF 的問題。

## ☁️ Google 試算表雲端同步與 PDF 轉檔設定

若您已部署過 **v16.0** 的後端腳本，**升級至 v17.0 無需重新修改 Google Apps Script**，原有的網頁應用程式網址可直接沿用；若為第一次設定或從 v15 以下版本升級，請依照以下步驟設定：

### 步驟 1：貼入 Apps Script 程式碼

1. 開啟您的 Google 試算表（[蓮花統計雲端資料庫](https://docs.google.com/spreadsheets/d/1QEzkn9SZuwxWNRVLw4RXSUzoWP8p-sxKg0yb1c_01Hs/edit)）。
2. 點擊上方選單 **「擴充功能」** → **「Apps Script」**。
3. 全選編輯器內的舊程式碼（`Ctrl + A`）並清空（`Delete`）。
4. 開啟隨附的純文字腳本檔 **`GAS_蓮花雲端腳本_v16.txt`**，全選複製（`Ctrl + A` → `Ctrl + C`）後貼入 Apps Script 編輯器（`Ctrl + V`）。
5. 點擊上方工具列的 **磁碟片圖示（儲存）**，確認無任何紅色錯誤波浪線。

### 步驟 2：發布新版本（讓更新生效）

1. 點擊編輯器右上角藍色按鈕 **「部署」** → **「管理部署作業」**。
2. 點擊右上角的 **鉛筆圖示（編輯）**。
3. 在「版本」下拉選單中，務必選擇 **「新版本」**（未選新版本將不會套用新功能）。
4. 點擊 **「部署」**（若首次使用或新增雲端硬碟權限，請依畫面提示點選「授權存取權」→「允許」）。

## 📱 Android APK 打包與安裝指南（WebIntoApp）

1. 準備最新打包素材壓縮檔：**`蓮花統計APP_APK打包素材-v17.zip`**（內含 `index.html` 與圖示 `icon.png`）。
2. 前往 **WebIntoApp** 網站，上傳該 `.zip` 素材包並生成最新 APK 檔案。
3. **安裝注意事項**：安裝新版本前，請先將手機上舊版的蓮花統計 APP **解除安裝**，再安裝剛打包好的 **v17.0 APK**，確保快取完全更新。

## 📄 如何匯出並檢視 A4 PDF 備料單

1. 在「✏️ 個人登記」、「📋 查詢與紀錄」或「📊 彙整總計」頁面中，點擊 **「📄 轉成 A4 PDF」**（或「匯出總計 PDF」）。
2. 在預覽視窗中可勾選：
   * **顯示備料核對框 (`□` / `☑`)**：方便列印後現場打勾確認（已在系統內勾選「已完成」的品項會直接顯示為 `☑`）。
   * **每人獨立一頁**（多筆匯出時顯示）：適合分發給不同人員核對。
3. 點擊 **「📥 下載 A4 PDF」**：
   * 在手機 APK 中會自動透過雲端產生標準直式 A4 PDF（暫存檔會在 24 小時後自動清理，不佔用雲端空間），下載完成後可直接在手機通知列或「檔案管理 → 下載」中開啟檢視。

## 📌 版本更新紀錄

* **v17.0**
  * 新增個人品項「已完成」勾選備註功能（支援「新增／編輯表單」與「查詢與紀錄卡片」雙向即時勾選）。
  * 已勾選完成之品項自動在明細文字附註 `（✓已完成）`，並同步反映於雲端試算表與 A4 PDF 核對框（`☑`）。
  * 同步更新網頁版 `蓮花統計工具-v17.html` 與打包素材包 `蓮花統計APP_APK打包素材-v17.zip`。

* **v16.0**
  * 新增 Google Apps Script 後端 `generatePdf` 實體 A4 PDF 產生器，解決 WebIntoApp Android APK 下載 PDF 無法檢視的問題。
  * 新增 24 小時自動清理 `蓮花A4_PDF暫存區` 機制，維持 Google 雲端硬碟整潔。
  * 提供獨立純文字腳本檔 `GAS_蓮花雲端腳本_v16.txt`，避免複製貼上產生引號轉義語法錯誤。

* **v15.x**
  * 支援富貴蓮（4 片）與掌心蓮（8 片）編號槽位勾選（允許重色與一鍵複製前 4 片）。
  * 支援一次新增多組同款蓮花獨立卡片與 Google 試算表雙向合併同步。
