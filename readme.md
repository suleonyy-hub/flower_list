# 🪷 參拜宮廟蓮花樣式顏色統計工具 (`v13.0`)

這是一款專為參拜宮廟備料與登記設計的**個人端離線網頁工具**（同時支援打包為 **Android APK**）。提供直覺的色塊勾選、動態品項新增、多條件查詢複製、跨人彙整總計、離線 A4 PDF 匯出，以及個人 Google 試算表雲端同步功能。

🌐 **線上使用網址（開啟 GitHub Pages 後）**：  
`https://suleonyy-hub.github.io/flower_list/`

---

## ✨ 核心功能特色

### 1. 彈性個人登記介面
* **13 色色塊快速勾選**：支援 **黃、粉紅、綠、紅、藍、白、紫、靛、橘、金、銀、黑、其他**，視覺化底色標示，降低看錯行與手寫錯誤。
* **動態選擇樣式／品項**：從下拉選單挑選需要的蓮花品項再動態帶出對應欄位，支援同一品項重複新增不同配色（自動標示 `#1`、`#2`）與一鍵複製微調。
* **完整部位規格**：
  * **菩提百合花盤**：花（選 4 朵）、葉（選 2 片）、母／寶璃珠、三教令。
  * **小花／水蓮花**：花色、葉子、八卦（附「同花色」快捷勾選）。
  * **大小花／大小水蓮花／雙瓣蓮花**：外層花色、內層花色、葉子、八卦（附「同外層」快捷勾選）。
  * **富貴蓮（4 片）／掌心蓮（8 片）**：採用花瓣編號槽位（`1～4`、`1～8`），點色依序填入並允許重色，掌心蓮另附「複製前 4 片 (`1~4 → 5~8`)」快捷鍵。
* **手機操作優化**：頂部固定快捷儲存列與表單底部留白設計，避免與 Android 系統返回鍵／導覽列重疊。

### 2. 多條件查詢與紀錄複製
* **複合篩選**：可依「參拜宮廟」、「參拜日期」與「關鍵字（姓名／品項／備註）」即時查詢歷史紀錄。
* **單筆與整批複製**：支援將單筆歷史紀錄複製為新紀錄，或將篩選出的整批人員紀錄一次複製到新宮廟與新日期。

### 3. 彙整總計與多格式匯出
* **跨人自動統計**：依宮廟與日期自動加總各品項總件數、人員明細，以及 13 色使用頻次（自動換算「同花色／同外層」與花瓣重色）。
* **離線產生標準 A4 PDF**：不需網路或系統列印支援，直接離線產出 A4 PDF 並自動命名為 `宮廟名_填寫人_日期.pdf`（支援備料核對框 `□` 與多筆每人獨立一頁）。
* **Excel (CSV) 與 JSON 備份**：支援匯出 UTF-8 CSV 供 Excel 開啟，並提供本機 JSON 備份與還原。

### 4. Google 試算表雲端同步
* 透過個人帳號的 Google Apps Script 連結至 Google 試算表，支援跨手機／電腦雙向合併同步、背景自動上傳，以及新裝置開啟時自動載入雲端紀錄。

## 🚀 使用方式

### 方式一：透過 GitHub Pages 直接使用（推薦）
1. 在本專案的 **Settings → Pages** 中，將 Branch 設為 `main` 並選擇 `/ (root)` 儲存。
2. 使用手機或電腦瀏覽器開啟 `https://suleonyy-hub.github.io/flower_list/`。
3. 在手機瀏覽器選單點選 **「加到主畫面」**，即可像一般 App 一樣快速開啟。

### 方式二：本機離線開啟
直接下載 `index.html`，在電腦或手機上以 Chrome / Safari / Edge 開啟即可離線使用。

### 方式三：打包成 Android APK 安裝
1. 將本專案的 `index.html` 與 `icon.png` 壓縮為 `.zip` 檔。
2. 前往 [WebIntoApp Maker](https://www.webintoapp.com/app-maker)，類型選擇 **HTML / Local Files**。
3. 上傳 `.zip` 檔與 `icon.png`，設定 App 名稱後點擊 **Make APP** 即可產出離線 `.apk` 安裝檔。

## ☁️ Google 試算表同步設定說明

若需更換或重新綁定個人 Google 試算表：
1. 在個人 Google 雲端硬碟建立一份新 Google 試算表，點選 **「擴充功能」→「Apps Script」**。
2. 開啟本工具右上角 **「☁️ 雲端同步」**，展開內建說明並複製 Google Apps Script 程式碼，貼上至編輯器後儲存。
3. 點擊 **「部署」→「新增部署作業」**，類型選擇 **「網頁應用程式」**，執行身分選「我」，誰可以存取選「**所有人**」。
4. 複製產出的 `/exec` 結尾網址，貼回工具的雲端同步設定並測試連線即可。
5. *(建議)* 若本專案設為公開（Public），請在 Apps Script 中的 `SYNC_TOKEN` 設定個人同步密碼，以保護雲端資料安全。
